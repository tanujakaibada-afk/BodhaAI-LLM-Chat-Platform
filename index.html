    About IntelliAI

    What is a Large Language Model?

    A Large Language Model (LLM) is an AI system trained on huge amounts of text. It learns patterns in language so it can predict the next word (token) in a sentence. By repeating this prediction, it can answer questions, summarize text, translate, write code and hold conversations.

    Purpose of this project

    IntelliAI is an educational project that shows how an LLM can be added to a real web application. It demonstrates a clean separation between a frontend (HTML, CSS, JavaScript) and a secure backend (Node.js + Express) that talks to the LLM provider.

    How it works

    1. You type a message in the browser.
    2. The frontend sends it to our backend at /api/chat.
    3. The backend validates it, attaches the secret API key from an environment variable, and calls the LLM.
    4. The reply travels back to the browser and appears as a chat bubble.

    Security highlights

    • The API key is stored in .env and never sent to the browser.
    • Inputs are validated and rate-limited on the server.
    • Messages are escaped before display to prevent XSS.

    Tech stack
